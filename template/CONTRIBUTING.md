# Contributing

## Workflow
1. Open or claim an issue.
2. Branch from `main`: `feat/<short-name>` or `fix/<short-name>`.
3. Run `make verify` locally before pushing.
4. Open a PR. CI green + 1 code owner approval required.
5. Squash-merge with conventional commit message.

## Architecture changes
Significant changes require an ADR in `docs/decisions/` before implementation.
