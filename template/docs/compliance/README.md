# Compliance Documentation

This folder maps repository practices to compliance frameworks. It is the
auditor-facing artifact set.

## Structure
- `policies/` — written policies required by ISO 27001 / SOC 2
- `soa/` — Statement of Applicability mapping each Annex A control to status
- `risk-register/` — risk identification, scoring, and treatment records
- `evidence/` — links and screenshots demonstrating controls in action

## Frameworks tracked
- ISO/IEC 27001:2022 (primary)
- SOC 2 Type II Trust Services Criteria
- NIST SSDF (SP 800-218)
